## Why it is outside the cycle

Maintenance does not follow a merge.
A dependency upgrade arrives when its maintainers release it, and a rule for the agent is worth writing the moment it repeats a mistake.
So these plugins sit under the map, not on its line: run them whenever the need comes up.

## What arrives and what leaves

- **Arrives:** a dependency and a target version, or a session in which you corrected the agent.
- **Leaves:** a safe / safe with changes / breaking verdict with evidence, or a rule that stops the mistake next time.
