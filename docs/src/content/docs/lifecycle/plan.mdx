## Why this stage

Give an agent a one-line request and it fills every gap with a guess.
The guesses surface late, as rework in review.
Planning moves those decisions to the start, where changing one costs a sentence instead of a branch.

## What to run

<StageCommands stage="plan" />

Most changes need only [`/fd3:build-spec`](/plugins/fd3/build-spec/).
Reach for [researcher](/plugins/researcher/) when a decision depends on a fact the code cannot answer, and for [codex-plan-improver](/plugins/codex-plan-improver/) when you want a second model to challenge a plan.

## What arrives and what leaves

- **Arrives:** an idea, an issue or a rough plan.
- **Leaves:** a spec whose load-bearing claims were checked against the code, ready to be split into tasks.
