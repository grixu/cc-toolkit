feature-delivery is deprecated. For new work, use [fd3](/plugins/fd3/), which covers the same ground with skills and dynamic workflows.

The two plugins share no file formats, so finish a project in the plugin you started it with.
The [plugin README](https://github.com/grixu/cc-toolkit/blob/main/plugins/feature-delivery/README.md) still documents its commands.
